# 绘图方法与可修改入口

## 1. 数据到图

`记录级冻结快照 → recount.py核验 → inputs绘图表 → build.py注入模板 → 本地D3与地形代码 → Chromium渲染 → PNG/SVG与校验报告`。

没有 LLM 生成图像，没有在线绘图服务，也不需要过去的v25、v30、v35或v36文件。当前模板已包含这些阶段最终采纳的实现。

## 2. 板块和共享海域

- 原生地形使用 `vendor/fantasy_maps_map.js` 中的 Voronoi 网格和程序化地形。网格数16,384，伪随机种子20261115。
- 领域分区使用带权距离分配，并迭代校准面积；面积响应指数0.35。布局参考数量、固定中心和手工边界补片共同保留已接受的版式，因此不能把区域面积理解成线性比例。
- 定向修形包括医学顶部、工程顶部、农业扩展及相邻中性碎片的归并。它们都保存在模板函数中，不依赖图片修补。
- 共享海域数量来自精确领域集合；几何位置、伸缩、角度、锚点来自 `inputs/selected_seas.csv`。渲染器重新进行成员接界和连通性检查。
- 现版不绘制河流、虚线领域边界或海域外框；右下图例和左下语料注释已移除。

## 3. 主题峰

读取正式三级标签，按去重记录数选择每领域前四类。高度振幅为：

```text
amplitude(n) = log(1 + n) / log(1 + 113)
```

113是当前44类中的最大记录数。全图共用这一高度尺度。峰宽另按本领域相对数量缩放：

```text
s = sqrt(n / maximum_count_within_field)
sigma_x = 0.029 + 0.033 × s
sigma_y = 0.025 + 0.027 × s
height(x,y) = maximum of the four local Gaussian peak fields
```

高度场叠加固定的微小起伏，再生成分层等高线与明暗、坡向阴影。峰宽有可读性下限，不能据此反推精确面积比例。地形只表示类别数量；它不使用科学贡献评分、引用数或质量评分。

山峰候选点优先留在自己的板块中，避开水域；峰群偏移在 `inputs/parameters.json`。保留v25曲折等高线实现与既定明暗参数，没有采用已被否决的v26形变，也没有添加按排名人工连接前两类的山脊。共享低位等高线是高度场连续的结果，不直接等于主题共现。

## 4. 英文标签和标记

- 44个主题名称按英文单词换行。布局避让领域名称、领域数量、海域数字、所有山峰标记及先前主题标签。
- 左下较拥挤区域有相对山峰位置的局部文字偏移，位于模板的 `localLabelPreferences`；这些偏移不移动山峰。
- 山峰标记半径2.4 SVG单位，灰色描边 `#657174`，线宽0.9，无填充。
- SVG的 `viewBox` 为 `-500 -500 1000 1000`，PNG输出1742×1742。
- Arial字体、浏览器及操作系统会影响文字宽度与抗锯齿；精确环境见 `reference/environment.json`。

## 5. 自动验证

`reproduce.py` 核验1,492个唯一记录、全部显示数量、44类排序、11个精确组合；验证11处水域的接界与连通、44个小灰圆环、全部英文标签及无重叠/裁切。基础网格和全部主题等高线路径与交付参考SVG逐项比较。报告同时记录文字位置是否完全一致、PNG SHA-256是否一致，以及渲染期间是否出现网络请求。

`--strict-pixels` 在这些检查之外，要求PNG逐字节一致。相同环境下的实际验证结果见 `REPRODUCTION_REPORT.md`。
