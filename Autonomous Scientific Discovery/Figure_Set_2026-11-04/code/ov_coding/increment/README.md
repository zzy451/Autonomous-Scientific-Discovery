# 662篇核心论文：问题开放度 O · 验证强度 V · 系统自主性 L（2026-11-04 增量）

依据以赵哲提案《From Computable Tasks to Open Science: A Chronicle of AI Problem Solving》为准：问题开放度 O1–O6、验证强度 V0–V4（V3–V4 为强验证：物理实验、形式化证明或第三方复现）、系统自主性 L0–L3。评判规则见 `RUBRIC.md`。

本增量为每篇核心论文增加三条轴的标签，并把它们写入**现有 papercard**（`Notes/**.md` 新增第 10 节），不另建第二套卡片。D1–D6 决策机制、科学对象归属、纳入状态均不改变。

## 方法

1. **证据包**：从每篇 papercard 截取书目信息、Evidence Log、摘要翻译、“最终科学问题”、实验与验证、局限性与风险，每行保留原笔记行号。
2. **编码**：Claude Sonnet 5.5（`claude-sonnet-5-5`，H20 上的 Claude Code，提示经 stdin 传入）按 rubric 逐篇编码，每篇给出 O、V、L、理由与 O/V 逐字引文。
3. **逐字校验**：脚本核对每条引文是否逐字存在于所注明的笔记行；行号有误但引文在别处逐字存在的自动更正（记录在 `line_corrected`）；其余不合格的论文在更严格的说明下重新编码，两轮后 662/662 全部通过。
4. **提案映射**：自主性 A0–A3 改名为 L0–L3；证据为机器可检验形式化证明的 V3 改为 V4（依提案“V4 证明/复现”），记录在 `mapping`。
5. **一致率**：30 篇分层试点由 Sonnet 5.5 与 Haiku 5.5 独立双编码（验证强度精确一致 93%、加权 kappa 0.93；开放度 kappa 0.51；自主性 kappa 0.60）；b01 的 29 篇另由 Codex gpt-6.1-sol 独立编码（验证强度加权 kappa 0.63）。不一致集中在 O3/O4、O4/O6、O1/O3、L1/L2 的边界，已据此在 rubric 中补充边界规则。

## 限制

- V 是论文**自身报告**的证据强度，不等于独立裁决的“已解决”；第三方复现在笔记中极少记录（V4 仅 2 篇）。
- 编码以 papercard 为据，未重读全文；109 篇标记需全文复核。
- rubric 中 V1/V2 边界、L0–L3 与 Wei 等人定义的对应、评判对象的取法，待提案作者确认后冻结（见 `RUBRIC.md` §6）。
