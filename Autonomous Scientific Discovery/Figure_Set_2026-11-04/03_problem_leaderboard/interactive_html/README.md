# Interactive leaderboard (standalone HTML, works offline)

**Classification:** content `03_problem_leaderboard` › form `interactive_html`

## Caption
One HTML file with all 662 papers embedded. It has headline figures, a status-by-field chart (click to filter), filters and search, and a sortable table with per-field rank, status, autonomy, mechanism, the verbatim problem statement and a live link.

## How it is generated
make_leaderboard_html.py. Scripts: `make_leaderboard_html.py` (run from `code/`).

## Versions

- `white/`: White background.
