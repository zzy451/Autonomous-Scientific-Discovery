# Constellation (mechanism sectors × autonomy rings)

**Classification:** content `07_autonomy_vs_verification` › form `constellation`

## Caption
Sectors are decision mechanisms (small ones widened, true counts printed). Rings are autonomy L1–L3, and each star is a paper. Colour = decision mechanism (LLM-driven, optimisation, hybrid, symbolic/planning). Brightness = verification strength: V3–V4 strong (physical experiment, formal proof or third-party replication), then V2, V1, V0.
