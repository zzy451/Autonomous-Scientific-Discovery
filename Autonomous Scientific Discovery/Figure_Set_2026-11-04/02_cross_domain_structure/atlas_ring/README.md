# Hierarchical edge-bundling ring (reference figure)

**Classification:** content `02_cross_domain_structure` › form `atlas_ring`

## Caption
Rings, from inside out: 173 third-level categories, 42 second-level categories, 11 fields; arc length is proportional to assignments. Each of the 422 curves joins the two categories of one paper in two fields; curves are bundled and coloured by decision mechanism.

## How it is generated
fig_atlas.py; hierarchical edge bundling with clamped cubic B-splines. Scripts: `fig_atlas.py` (run from `code/`).
