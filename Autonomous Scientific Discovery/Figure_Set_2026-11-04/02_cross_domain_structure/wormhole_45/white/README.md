## Caption
The atlas ring is repeated per era (2004–2019 … 2026) along a 3D time axis, viewed at 45°. Each ring has a radius proportional to the square root of that era's assignments and holds that era's cross-field curves. Each dot sits on an autonomy track (L0 innermost, L3 at the rim). Translucent curtains carry each field's arc from era to era.
