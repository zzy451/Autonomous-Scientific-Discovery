# Evidence thins over time

**Classification:** content `08_evidence_over_time`

## Proposal claim
Case counts rise quickly while the evidence behind 'solved' weakens (§2(2)).

**Verdict:** Supported

## Analysis
Strong verification falls from 67% (2004–2019) and 93% (2020–2023) to 36%, 23% and 9% in 2024–2026, while weak papers (V0–V1) rise 0, 1, 18, 48 and 130. This mirrors the proposal's 0/1/4/13 and 5/7 → 12/41.

## Limits
2026 is incomplete.
