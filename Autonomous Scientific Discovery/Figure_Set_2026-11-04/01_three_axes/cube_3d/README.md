# Openness × verification × autonomy cube (3D)

**Classification:** content `01_three_axes` › form `cube_3d`

## Caption
The proposal's three-way classification as one 3D space: x = problem openness O1–O6, y = verification strength V0–V4, z = system autonomy L0–L3. Every occupied (O, V, L) cell is a bubble with its paper count; area is proportional to papers and colour gives the V level (warm = strong, V3–V4). Tick labels carry each level's total, and drop lines mark the O × V position on the floor. The sheet repeats the cube for all papers and for each of the 11 fields, on one shared bubble scale.

## How it is generated
fig_axes3d.py (matplotlib mplot3d); every count is in derived/ovl_cube_counts.csv. Scripts: `fig_axes3d.py` (run from `code/`).
