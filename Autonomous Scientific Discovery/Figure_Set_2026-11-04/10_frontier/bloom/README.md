# Frontier bloom (polar petals)

**Classification:** content `10_frontier` › form `bloom`

## Caption
Each field is a petal with radius O1 (centre) to O6 (rim). Each era adds one translucent layer marking openness reached with strong verification; the outline marks the highest openness attempted. Colour = decision mechanism (LLM-driven, optimisation, hybrid, symbolic/planning). Brightness = verification strength: V3–V4 strong (physical experiment, formal proof or third-party replication), then V2, V1, V0.

cover_bloom.py. Scripts: `cover_bloom.py` (run from `code/`).
