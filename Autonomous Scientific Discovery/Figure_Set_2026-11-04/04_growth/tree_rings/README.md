# Tree rings (eras × fields)

**Classification:** content `04_growth` › form `tree_rings`

## Caption
Rings are eras, from 2004–2019 at the core to 2026 outermost; each annulus has area proportional to its assignments. Sectors are fields; each dot is one assignment. Colour = decision mechanism (LLM-driven, optimisation, hybrid, symbolic/planning). Brightness = verification strength: V3–V4 strong (physical experiment, formal proof or third-party replication), then V2, V1, V0.

## How it is generated
cover_rings.py. Scripts: `cover_rings.py` (run from `code/`).
