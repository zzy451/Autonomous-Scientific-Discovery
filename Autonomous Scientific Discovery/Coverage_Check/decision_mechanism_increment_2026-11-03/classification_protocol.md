# 662篇核心论文：主导决策机制增量分类规范

日期：2026-11-03。范围：2026-11-01冻结核心清单的662篇唯一工作。用户指定六类互斥标签；每篇恰好一个主标签。此目录为增量分析，不修改主表、Data、Notes、既有审计、正文或PPT，不改变科学对象归属和纳入状态。

## 六类

| 代码 | 名称 | 判据 |
|---|---|---|
| D1 | 符号/知识推理型 | 逻辑规则、显式知识表示、可执行规则/约束或结构化知识推导主导科研判断。仅调用证明器/知识图谱作为工具不充分。 |
| D2 | 规划/模型驱动型 | 显式任务、环境、状态转移或科学模型上的搜索/规划/诊断重规划主导下一步行动；普通物理计算、LLM生成计划本身不充分。 |
| D3 | 优化/概率决策型 | 目标函数、采集函数、概率信念/不确定性、主动学习、贝叶斯优化、进化搜索等决定候选或下一实验。预测模型本身不是决策器。 |
| D4 | 学习策略型 | 非LLM的学习策略/控制器由交互、示范、奖励或数据训练后主导行动；强化学习训练的LLM在部署时自主语言推理选行动，原则上归D5。 |
| D5 | LLM 驱动型 | LLM提出、评估或选择关键科研行动，工具、检索、代码、知识图谱、验证器服务其决策；多Agent、RAG、具身、规划等辅助属性不自动变成D6。 |
| D6 | 混合机制型 | 两种或多种上述机制分别承担不可替代的候选生成/选择/更新决策，证据支持共同控制且不能合理识别主导机制。未知/旧Hybrid标签不能作为D6的充分依据。 |

## 操作边界

1. 单位是论文提出/重点评估的Agent系统，不是对比基线。比较多种独立机制的论文先识别主系统；若无唯一主系统且确实共同研究多个机制，注明论文层面聚合限制并降低置信度，不虚构系统内耦合。
2. 先识别关键动作（选择实验/假设/目标/观测/工具/分析步骤），再识别谁按什么机制决定该动作。研究对象、年份、标题词、旧类型、是否机器人不直接决定新标签。
3. 概率目标/采集函数选实验通常D3；任务约束下状态/行动序列规划通常D2；逻辑规则演绎通常D1；非LLM学得的行为策略D4；LLM部署时推理选科研动作D5。
4. LLM+普通工具/检索/模拟/硬性安全检查仍可D5。LLM生成候选而独立进化/BO选择与更新对研究搜索同等关键时可D6。只有LLM外壳、核心实验选择由BO承担时D3。
5. 按证据做出六类中的最佳判断；证据弱则confidence=low、provisional=true、needs_fulltext_review=true。未审阅不等于证据不足；不添加第七类，不把低置信度混入高置信统计。
6. 全部至少阅读逐篇笔记的机制相关片段；不足时读取笔记方法/证据日志，必要时核对本地PDF/已有全文缓存。旧标签仅加速定位。不得声称全库重新阅读全文，除非实际完成并有来源位置。
7. 每篇保存唯一代码、中文具体理由、旧标签、证据来源及原文片段、置信度、复核状态。区分笔记转述与本轮直接核对原文。证据引用必须逐字可回溯，不杜撰引文或页码。

### 实际边界补充

- 语言模型骨干加训练后的行动评分/选择头，若语言模型仍是核心候选评估与行动选择者，可归D5；不因GRPO或action head自动变成非LLM D4。例如MolReAct的Qwen-3-4B决策模型。
- 固定成功判据、分数回滚、停止阈值、编译器反馈或LLM judge本身不自动构成D6。须有额外机制对科研搜索/行动作实质选择，而非仅判断已生成结果是否合格。
- AEGIS等自主选点若由显式特征评分、加权目标排序和取最大值控制，按D3；不能只因旧Planning标签归D2。专家手写规则把表征分成pass/fail再触发后续实验，按D1（如Dai机器人化学家）。
- Protein language model产生蛋白候选但低样本fitness predictor/主动学习决定下一实验，通常D3；蛋白语言模型不自动等同部署时语言推理Agent。
- 一个论文有多个独立被评系统时，唯一标签是按论文核心系统/共同主干做的概括，必须说明限制；不能把并列系统虚构为内部混合架构。
- LLM选择实验，符号任务—运动规划器仅将既定实验转成可执行机器人动作，通常D5；科研选择与执行可行性规划不能混为两个同等科研决策器。CLAIRify、Organa采用此边界。
- 提到evolutionary optimization但只明确语言Agent提议及固定门控接纳，未描述独立种群/搜索分支/采集控制时，不据此判D6。Agent Genesis免疫世界模型保守暂归D5并保留复核；MatPilot按可识别认知机制归D5。

## 多Agent分工与输出

用户指定gpt-6.1-sol、high。A/B/C三个Agent各审阅一个不相交批次，仅在本增量目录各自的reviewer_A.jsonl、reviewer_B.jsonl、reviewer_C.jsonl和各自scratch子目录写文件；其余所有源文件只读。主控合并、核对边界、完整性和证据引用，追加controller_review.jsonl，不覆盖原审阅输出。

每个审阅JSONL记录至少含：paper_id, decision_class(D1-D6), rationale_zh, evidence_quote(笔记原句), evidence_note_line(1-based), confidence(high/medium/low), provisional(bool), needs_fulltext_review(bool), source_basis(note / note_and_pdf / note_and_cached_fulltext / note_and_primary_web), primary_source_excerpt(可空), primary_source_locator(可空)。读取PDF必须记录实际页码；仅引用笔记中写出的PDF位置不算本轮全文核实。

这是一套服务于当前综述的操作性编码，不宣称六类是学界唯一标准，也不把论文数当成机制性能或成熟度排名。
