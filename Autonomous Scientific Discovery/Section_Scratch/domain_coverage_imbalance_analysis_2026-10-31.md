# 11个学科文献数量不均衡的解释分析（2026-10-31）

## 分析目的

当前核心库有663篇不同工作，654篇有具体科学对象归属，形成926个非互斥的工作—领域归属。11个模块的覆盖量从材料科学的172篇到农业、食品、林业、动物与渔业科学的9篇不等。这个差异不能直接解释为全球研究规模差异。本材料用于支撑正文新增章节 `Why Domain Coverage Is Uneven`，把观察到的数量差异拆解为检索路径、工作流适配性、工具与实验条件、评价端点、发表和命名习惯、时间因素及多模块分类共同作用的结果。

## 主要解释机制

### 1. 数量首先是当前收集路径的产物

本项目从种子综述引用网络、高影响力期刊入口、前向/后向引用和定向关键词检索扩展。这样的路径更容易发现英文、可索引、与综述或高影响力论文有引用连接、并使用 `agent`、`autonomous`、`tool use`、`benchmark` 等术语的工作。形式与计算科学、化学和材料科学恰好高度符合这些条件，因此更容易形成可继续扩展的引用簇。农业、任务系统和海洋研究的合格论文可能分散在机器人、遥感、现场科学和任务工程来源中，未必形成同样清晰的 Agent for Science 引用网络。

### 2. 不同学科的工作流可代理化程度不同

材料、化学、工程以及部分生命和医学研究具有机器可读输入、成熟模拟包、标准化实验协议、机器人设备或可重复测定，容易形成“提出候选—执行—测量—选择下一步”的可见闭环。农业、生态和地球环境研究更常受到季节性、现场异质性、地理尺度和仪器配置影响；航空航天和海洋任务还受到硬件时间、认证和长期任务周期限制。这些因素降低了可快速复用、可连续发表的 Agent 工作流数量。

### 3. 反馈速度和评价端点不同

程序分数、仿真输出、反应分析、材料性质和生物测定比较容易成为明确的评价端点。社会机制、生态机制、临床决策或任务科学回报通常需要更长时间、更复杂的混杂控制或外部验证。因此，高覆盖模块并不等于科学结论验证更强；低覆盖模块也不等于没有重要研究，而可能是验证周期更长、结果更难标准化。

### 4. 数据、工具和基础设施的开放程度不同

计算科学、材料、化学、生物和医学已经积累大量公开数据、软件、基准和实验平台，后续工作可以复用相同工具并发表增量结果。农业数据往往分散在地区、作物、季节和传感器条件中；地球环境数据虽然丰富，但从观测到机制解释仍有较长链条；航天和海洋硬件则昂贵且难以复现。工具可访问性影响论文能否构造 Agent 行动链，也影响其他研究者能否复核和扩展。

### 5. 发表场所和命名习惯会造成可见性差异

近期大语言模型智能体研究集中在已经形成共享软件栈、公开基准和共同系统命名的领域。农业论文可能使用 `phenotyping`、`decision support` 或 `data analysis`，历史航天论文可能使用 `planning`、`scheduling`、`mission operations` 或 `robotics`，但它们仍可能满足本项目的四项 Agent 纳入标准。检索词和引用扩展若偏向现代 Agent 术语，就会低估这些历史或领域化谱系。

### 6. 时间结构不对称

航空航天和机器人科学中有一批早期合格系统，出现时间早于现在的 Agent for Science 术语，因而作为历史锚点存在，而不是形成大规模现代引用簇。相反，2024—2026 年大语言模型智能体的快速增长会使计算、化学、材料、生物和医学在当前窗口内显得更密集。2026 H1 还是前沿更新层，不应与完整年度直接比较。

### 7. 多模块分类改变了可见总量

196篇工作产生926个非互斥工作—领域归属。一篇论文如果分别评估了化学反应和材料性质，可以同时归入03和04；这避免把跨领域证据隐藏在主归档领域中，但也会增强相邻高密度模块的可见度。相反，只有应用设想而没有对象级实验的通用系统仍进入01.04，不会因为声称覆盖多个领域而增加11个正式模块的数量。

## 各模块的具体解释

- **01**：Agent术语、代码、基准和可执行评价器较成熟，因此容易检索和复用；数量不代表证明正确或算法新颖。
- **02**：仪器、仿真和公开数据提供明确任务，但物理发现、参数推断和仪器运行仍是不同证据层级。
- **03**：合成程序、反应空间、分析仪器和机器人化学形成强引用谱系；数量多不等于多数论文发现新反应。
- **04**：自驱动实验室、组成—结构—性能目标和快速优化反馈共同推动其成为最高覆盖模块；代理性质优化仍不等于器件性能或材料理解。
- **05**：遥感与传感器工作流较易纳入，但环境机制解释的证据链更长，且与10存在对象边界。
- **06**：生物数据、扰动实验和单细胞流程丰富；回顾性分析或扰动选择不自动等于因果生物学发现。
- **07**：医学基准、电子病历和药物设计带来较多论文；基准、结合或表达实验不等于临床获益。
- **08**：术语和发表渠道分散，现场与季节条件复杂，公开 Agent 基准少；9篇是收集特征，不是科学重要性排序。
- **09**：模拟和设计工具成熟，但工程子领域分散，物理验证要求不一；仿真执行率不是统一工程有效性指标。
- **10**：硬件、认证和任务周期使论文难以快速复制；论文少不等于自主性弱，历史系统也可能被其他术语索引。
- **11**：学术数据、科学计量、同行评审和社会模拟易于构造基准，但模拟内部一致性不能证明人类行为机制。

## 对后续检索和正文论证的影响

下一轮扩展不应只追求在04、06、07等高密度模块继续增加数量，而应优先寻找08、10、05以及11.07中的遗漏谱系和边界案例。未来统计必须同时报告唯一工作数和非互斥归属数，保留检索路径和时间截点，并把工作流执行、任务正确性和科学结论支持分开。低覆盖领域应被视为需要定向补检和证据深化的区域，而不是被动解释为研究不足。
