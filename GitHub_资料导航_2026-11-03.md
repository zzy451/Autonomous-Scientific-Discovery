## 2. 逐篇书目信息、笔记与 PDF

主台账保存标题、作者、年份、来源、DOI／URL、纳入状态、科研对象归属、旧辅助标签、笔记和 PDF 路径，以及备注中的来源线索。核心清单是筛出的 662 篇核心工作入口，包含固定 `paper_id`、引用键、细分领域路径和资产位置。

- **笔记：662 篇核心论文均有笔记。**文件按主归档领域存放于 `Notes/`，内容包括纳入和归类依据、方法流程、科研角色、实验任务、指标、贡献和局限等；各篇的详细程度不完全相同。
- **PDF：635 篇核心论文有本地归档文件，且对应文件已进入仓库。**目录按主归档领域组织，采用 Git LFS 管理。同一篇跨领域论文不需要复制多份 PDF。
- **逐篇查找方式：**先在核心清单中搜索题名或 `ASD-xxxx`，读取 `note_path`、`pdf_path` 和 `citation_key`；笔记和 PDF 的路径相对 `Autonomous Scientific Discovery/`。
- **PDF 清单：**[`Data/pdf_manifest.json`](https://github.com/zzy451/Autonomous-Scientific-Discovery/blob/main/Autonomous%20Scientific%20Discovery/Data/pdf_manifest.json)。缺少本地 PDF 的记录见 [`Data/missing_pdf_manifest.json`](https://github.com/zzy451/Autonomous-Scientific-Discovery/blob/main/Autonomous%20Scientific%20Discovery/Data/missing_pdf_manifest.json)。
- **笔记清单：**[`Data/note_manifest.json`](https://github.com/zzy451/Autonomous-Scientific-Discovery/blob/main/Autonomous%20Scientific%20Discovery/Data/note_manifest.json)。

克隆仓库后，在仓库根目录运行 `git lfs pull` 获取已发布 PDF 的实际内容；普通 Git 文件中的 LFS 指针不是论文全文。

## 7. 使用时的口径

- **独立论文与领域归属分开计数：**核心工作 662 篇，正式领域归属 935 项。
- **按 ID 关联：**主台账、核心清单、引用桥和新增决策机制分类通过 `ASD-xxxx`／`paper_id` 对齐。
- **旧标签与新分类分开理解：**旧 Agent 类型可以多选，且描述技术、组织与形态；新 D1—D6 描述主导决策机制，每篇仅一类。
- **发布来源与检索来源分开理解：**期刊、会议、预印本是书目来源；种子综述和引文扩展等是发现路径。
- **案例字段与全库编码分开理解：**人机决策责任、协作拓扑、科学贡献归因、验证独立性和外部有效性尚无完整的全库统一编码。
